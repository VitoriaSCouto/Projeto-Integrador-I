# 🌪️ Projeto Integrador I — Bot de Assistência a Desastres Naturais

## 📌 Descrição
Este projeto consiste em um bot de mensagens automatizadas desenvolvido para prestar assistência a pessoas afetadas por desastres naturais, como enchentes, deslizamentos, incêndios e tempestades.

O sistema tem como objetivo fornecer informações rápidas, orientações de segurança e apoio inicial às vítimas, utilizando comunicação automatizada para alcançar o maior número de pessoas possível em situações de emergência.

---

## 🎯 Objetivos
- 📢 Disseminar informações importantes em tempo real  
- 🚨 Orientar vítimas sobre procedimentos de segurança  
- 📍 Direcionar usuários para abrigos e serviços de emergência  
- 🤖 Automatizar respostas para agilizar o atendimento  

---

## ⚙️ Funcionalidades
- Envio automático de mensagens
- Respostas pré-configuradas para situações de emergência
- Estrutura baseada em controllers
- Organização modular para fácil manutenção

---

## 🛠️ Tecnologias Utilizadas
- Node.js
- JavaScript
- (Possível integração com APIs como WhatsApp, Telegram ou SMS)

## 🚀 Como Executar o Projeto

### Pré-requisitos
- Node.js instalado
- Gerenciador de pacotes (npm ou yarn)

### Passos
```bash
# Clone o repositório
git clone https://github.com/OSeuPiupiu/Projeto-Integrador-I.git

# Acesse a pasta do projeto
cd Projeto-Integrador-I

# Instale as dependências
npm install

# Execute o projeto
node index.js
```

---

## 📖 Como Funciona
O bot recebe mensagens dos usuários e responde automaticamente com base em regras e fluxos definidos nos controllers. Ele pode ser adaptado para diferentes cenários de desastres naturais, oferecendo respostas específicas conforme o contexto.
